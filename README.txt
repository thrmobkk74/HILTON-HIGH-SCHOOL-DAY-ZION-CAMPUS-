Open index.html in a browser for the public preview. Open admin/index.html for the admin preview.

This build starts from Preview v2. The existing school pages, wording, and developer page were preserved. The supplied Hilton High School Zion Campus badge is placed in the original badge asset location.

Admin preview controls include badge replacement/removal/restoration, background image replacement/removal, multiple image preview, and home-page school name/motto/welcome editing. These controls store changes in the same browser using localStorage; they do NOT sync to other devices or publish online. A hosted backend/database and deployment are still required for genuine multi-device updates and secure admin authentication.

For best results, extract the complete ZIP first, then open index.html in a browser. Do not preview the HTML inside the ZIP viewer. The developer page is unchanged and is not included in the normal editing controls.
